## 🤝 Contributing

We welcome contributions from students who have successfully completed their **Final Viva**. This repository aims to build a collaborative collection of student projects related to **Water-Borne Diseases**, providing a valuable learning resource for future students, researchers, and developers.

### 🎓 How Students Can Contribute

After successfully completing your Final Viva, follow these steps to submit your project:

1. **Fork the Repository:** Fork this repository to your GitHub account.

2. **Select the Appropriate Category:** Navigate to the relevant category of Water-Borne Diseases and create a new folder for your project. Please maintain alphabetical order where possible.

3. **Create Your Project Folder:** Name your folder using the following format:

   `Project Name - Student Name (Student ID)`

4. **Include the Required Project Files:** Your project folder must contain the following:

   - **Project Description (`Project_Details.md`):** A detailed description of your project, including its objectives, scope, methodology, technologies used, features, and implementation details.
   - **Complete Source Code:** Upload all source code files required to run your project.
   - **Complete Project Diagrams:** Include relevant diagrams, such as system architecture, flowcharts, ER diagrams, use-case diagrams, or other applicable design diagrams.
   - **Additional Resources (Optional):** Include screenshots, datasets, installation instructions, or other supporting materials where applicable.

5. **Review Your Submission:** Before submitting, ensure that:
   - Your project is complete and functional.
   - All required files are included.
   - The documentation is clear and properly organized.
   - No passwords, API keys, or confidential information are included.

6. **Submit a Pull Request:** Once your Final Viva is successfully completed, create a Pull Request (PR) from your forked repository.

   Your Pull Request should include:
   - Project name and student name.
   - Student ID.
   - A brief description of the project.
   - Confirmation that the project has successfully completed its Final Viva.

7. **Follow Contribution Guidelines:** Please read the repository's contribution guidelines before submitting:

   [CONTRIBUTING.md](https://github.com/dr-mushtaq/Awesome-AI-Tools-Resources/blob/main/CONTRIBUTING.md)

---

### 💡 Alternative: Contribute Through GitHub Issues

Not familiar with Git, GitHub, or Pull Requests?

No problem! You can still share your project by opening a **GitHub Issue** in this repository.

Please include the following information:

- Project Name
- Student Name
- Student ID
- Project Description
- Confirmation of Final Viva completion
- GitHub repository link (if available)

Alternatively, you may send your project details to:

📧 **Email:** mushtaq.hussain@vu.edu.pk

### ⭐ Important Notes

- Only projects that have successfully completed the Final Viva should be submitted.
- Students are responsible for ensuring that their submitted code and documentation are complete.
- All contributions will be reviewed before being merged into the repository.
- Properly documented and organized contributions help future students learn, explore, and build upon previous projects.
